# Heaps and Priority Queues

## Must know

- A heap is a nearly complete binary tree stored in an array.
- Python `heapq` implements a min-heap.
- Use negative numbers to simulate a max-heap.
- Heap operations are usually `O(log n)`.

## Implement

- `heappush`
- `heappop`
- `heapify`

## Patterns

- Top k.
- K-way merge.
- Scheduling.
- Dijkstra's algorithm.
