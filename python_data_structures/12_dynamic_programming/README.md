# Dynamic Programming

## Must know

- Dynamic programming is useful when a problem has overlapping subproblems and optimal substructure.
- Memoization is top-down caching.
- Tabulation is bottom-up table filling.
- The hardest part is often defining the state.

## Practice process

1. Define the state.
2. Write the recurrence.
3. Choose base cases.
4. Decide memoization or tabulation.
5. Check time and space complexity.

## Patterns

- 1D DP.
- 2D DP.
- Knapsack.
- Longest subsequence.
- Grid paths.
