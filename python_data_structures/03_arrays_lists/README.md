# Arrays and Lists

## Must know

- Python `list` is a dynamic array, not a linked list.
- Indexing and appending are fast.
- Inserting or deleting near the front is expensive because elements shift.
- Slicing creates a new list.

## Implement

- A small `DynamicArray` class.
- Manual insert, delete, resize, and search operations.

## Patterns

- Two pointers.
- Sliding window.
- Prefix sums.
- In-place reversal.
