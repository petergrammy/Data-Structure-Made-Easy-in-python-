# Resources

Pick one main textbook and use the others as references. More resources are not automatically better; depth beats collecting links.

## Recommended textbooks

1. `Problem Solving with Algorithms and Data Structures using Python`
   - Link: https://runestone.academy/ns/books/published/pythonds/index.html
   - Best for: your main course-prep book.
   - Why: approachable, Python-based, includes analysis, stacks, queues, lists, recursion, sorting, trees, and graphs.

2. `Data Structures and Algorithms using Python` by Rance D. Necaise
   - Link: https://datastructures.necaise.org/TableOfContents
   - Best for: clear ADT thinking and implementation practice.
   - Why: good if your course emphasizes building structures from scratch.

3. `Open Data Structures` by Pat Morin
   - Link: https://opendatastructures.org/
   - Python/pseudocode edition: https://opendatastructures.org/ods-python/
   - Best for: deeper theory and rigorous analysis.
   - Why: excellent coverage of lists, hash tables, trees, heaps, graphs, and more advanced structures.

4. `Data Structures and Algorithms in Python` by Goodrich, Tamassia, and Goldwasser
   - Companion site: https://bcs.wiley.com/he-bcs/Books?action=index&bcsId=8028&itemId=1118290275
   - Best for: a classic university-style textbook.
   - Why: comprehensive and more formal; useful if your class is proof-heavy or implementation-heavy.

## Recommended GitHub repositories

1. TheAlgorithms/Python
   - Link: https://github.com/TheAlgorithms/Python
   - Use it for: reading many implementations after you have tried your own.
   - Caution: it is broad; do not wander randomly. Search inside `data_structures`, `sorts`, `searches`, `graphs`, and `dynamic_programming`.

2. keon/algorithms
   - Link: https://github.com/keon/algorithms
   - Use it for: compact Pythonic examples.
   - Caution: treat it as a reference, not as a source to memorize.

3. awwalm/DSAlgoPy
   - Link: https://github.com/awwalm/DSAlgoPy
   - Use it for: chapter-style practice aligned with common DSA textbooks.
   - Caution: compare its organization with your course syllabus and skip mismatched chapters.

## Practice sites

- LeetCode: best for interview-style patterns.
- HackerRank: useful for beginner-to-intermediate drills.
- CodeSignal: good for short repetition.
- Visualgo: useful when a structure is hard to picture.

## How to read implementations

Use this order:

1. Predict the API before reading the code.
2. Read the public methods first.
3. Trace one small example by hand.
4. Write the code yourself without looking.
5. Compare your code against the reference.
6. Add the operation costs to your notes.
