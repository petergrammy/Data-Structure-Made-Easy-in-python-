# Python Data Structures Learning Folder

This folder is built for someone who is already comfortable writing Python, but wants data structures to become solid, usable knowledge.

## How to use this folder

1. Read `00_resources/README.md` and choose one main textbook.
2. Follow `STUDY_PLAN.md` week by week.
3. For each topic folder, read its `README.md`, implement the structures yourself, and solve the suggested problems.
4. Keep personal lecture notes in `14_course_notes/`.
5. Track solved problems in `13_practice_problems/problem_log.md`.

## Folder map

- `00_resources/`: textbooks, GitHub repositories, and practice sites.
- `01_big_o/`: time complexity, space complexity, amortized analysis.
- `02_python_collections/`: Python's built-in containers and when to use them.
- `03_arrays_lists/`: arrays, dynamic arrays, Python lists, slicing costs.
- `04_linked_list/`: singly linked lists, doubly linked lists, pointer-style reasoning in Python.
- `05_stack_queue_deque/`: stacks, queues, deques, monotonic stacks and queues.
- `06_hashing_hash_tables/`: hash codes, `dict`, `set`, collisions, custom `__hash__`.
- `07_recursion/`: recursion, call stacks, divide and conquer.
- `08_trees/`: binary trees, BSTs, traversals, balanced-tree ideas.
- `09_heaps_priority_queue/`: heaps, priority queues, `heapq`.
- `10_graphs/`: graph representations, BFS, DFS, shortest paths.
- `11_sorting_searching/`: sorting algorithms, binary search, selection.
- `12_dynamic_programming/`: memoization, tabulation, recurrence thinking.
- `13_practice_problems/`: problem log and review notes.
- `14_course_notes/`: class notes, homework notes, exam review.

## Weekly rhythm

Use this loop for every topic:

1. Concept: explain the structure in plain English.
2. API: list the operations it supports.
3. Cost: know the Big-O of each operation.
4. Implementation: write it from scratch once.
5. Pythonic version: solve the same task with Python's standard tools.
6. Problems: solve 5 to 10 exercises.
7. Review: write down mistakes and patterns.
