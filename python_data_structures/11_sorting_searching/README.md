# Sorting and Searching

## Must know

- Python's built-in sorting is stable and highly optimized.
- You still need to understand classic sorts for analysis and exams.
- Binary search is a pattern, not just a single function.

## Implement

- Insertion sort.
- Merge sort.
- Quicksort.
- Binary search.
- Binary search on answer.

## Patterns

- Search exact value.
- Search first true.
- Search lower bound.
- Merge intervals.
- Sort by custom key.
