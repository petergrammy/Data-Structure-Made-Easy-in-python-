# Trees

## Must know

- Trees are hierarchical structures.
- Binary trees have at most two children per node.
- Binary search trees keep left values smaller and right values larger.
- Traversal order matters.

## Implement

- Binary tree node.
- Recursive traversals.
- Iterative traversals.
- Binary search tree insert, search, and delete.

## Patterns

- DFS recursion.
- BFS level order.
- Lowest common ancestor.
- Validate BST bounds.
- Height and diameter.
