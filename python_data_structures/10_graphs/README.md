# Graphs

## Must know

- Graphs can be directed or undirected.
- Graphs can be weighted or unweighted.
- Adjacency lists are the usual default representation.
- BFS gives shortest paths in unweighted graphs.
- DFS is useful for traversal, cycle detection, and components.

## Implement

- Graph as `dict[node, list[node]]`.
- BFS.
- DFS recursive and iterative.
- Topological sort.
- Dijkstra's algorithm.

## Patterns

- Connected components.
- Grid BFS.
- Cycle detection.
- Shortest path.
- Dependency ordering.
