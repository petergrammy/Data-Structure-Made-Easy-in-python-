# Python Collections

## Must know

- `list`: dynamic array.
- `tuple`: immutable sequence.
- `dict`: hash table mapping keys to values.
- `set`: hash table storing unique keys.
- `collections.deque`: efficient queue/deque.
- `collections.Counter`: frequency map.
- `collections.defaultdict`: dictionary with automatic default values.
- `heapq`: functions for using a list as a min-heap.

## Exercises

- Solve frequency-count problems with `dict`, `defaultdict`, and `Counter`.
- Compare `list.pop(0)` with `deque.popleft()`.
- Build a cheat sheet of operation costs.
