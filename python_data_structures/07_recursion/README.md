# Recursion

## Must know

- Every recursive function needs a base case.
- Every recursive call should make progress toward the base case.
- Recursion uses the call stack.
- Many tree and graph algorithms are naturally recursive.

## Practice

- Trace calls manually.
- Draw the recursion tree.
- Convert a recursive solution into an iterative one using a stack.

## Patterns

- Divide and conquer.
- Backtracking.
- Tree traversal.
- Memoization.
