# Linked Lists

## Must know

- A linked list is made of nodes connected by references.
- Access by index is slow.
- Insertion and deletion are efficient only when you already have the relevant node.
- Dummy head nodes simplify edge cases.

## Implement

- `Node`
- `SinglyLinkedList`
- `DoublyLinkedList`
- `append`, `prepend`, `find`, `delete`, `reverse`

## Patterns

- Dummy node.
- Fast and slow pointers.
- Reverse links.
- Merge two chains.
